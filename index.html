¿Cómo funciona?

Este proyecto utiliza un modelo de Inteligencia Artificial entrenado mediante Google Teachable Machine para identificar vasos de cuatro colores diferentes.

1. Capturamos

La cámara obtiene una imagen.

2. Analizamos

El modelo analiza la imagen.

3. Calculamos

Se calcula la probabilidad de cada clase.

4. Clasificamos

Mostramos la clase con mayor probabilidad.
